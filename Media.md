# Media that travels with your notes

A saved file can carry something a paragraph cannot: a picture, a finished diagram, a page layout, or the sound of a reminder. Keep it beside the note that gives it context.

## A short spoken note

[Play Evening reminder.m4a](Formats/Evening%20reminder.m4a) using Open system preview or Share.

**Transcript:** Take a notebook, choose one question, and leave room for surprise. Before you head home, write down one detail you want to remember. Tomorrow, connect it to something you have read.

This example uses a synthetic voice. Mementara does not transcribe the recording; the transcript above is an ordinary note you can search.
