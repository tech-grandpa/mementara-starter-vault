# One project, many kinds of notes

A notebook does not have to stop at Markdown. These small examples belong to the same fictional evening-observation project, so opening a different format still feels like following the same thought.

## Read and discover

| Example | What to notice |
| --- | --- |
| [Astronomy.pdf](Astronomy.pdf) | Three designed pages with a real text layer. Search results can open a matching page. |
| [Clipping.html](Clipping.html) | A saved article with a readable text preview. Scripts and remote assets are not loaded. |
| [Reading list.csv](Reading%20list.csv) | A compact reading queue; text inside rows is searchable. |
| [Evening plan.yaml](Evening%20plan.yaml) | A readable plan in a structured text format. |
| [Observation log.json](Observation%20log.json) | A small collection of notes, tags and follow-up questions. |

## Think visually

| Example | What to notice |
| --- | --- |
| [Research.drawio](Research.drawio) | A two-page research workflow with searchable labels. |
| [Project.canvas](Project.canvas) | Text cards, file references and their connections. |
| [Sketch.excalidraw](Sketch.excalidraw) | A rough visual idea with a selectable Text view. |
| [Mind map.excalidraw.md](Mind%20map.excalidraw.md) | An uncompressed Obsidian-style drawing inside Markdown. |
| [Compressed map.drawio](Compressed%20map.drawio) | A small native drawing saved with compressed XML. |

These use a simplified local preview. Styling, custom shapes and embedded content can differ from the original editor. [[Media#An exported diagram|Media]] also shows an explicitly exported SVG beside its source.

## Keep the original document

[Evening checklist.docx](Evening%20checklist.docx), [Rich note.rtf](Rich%20note.rtf) and [Evening reminder.m4a](Evening%20reminder.m4a) open through supported system previews or Share. Search finds their filenames; Office text and audio are not indexed.
