# Getting started

## Your first vault

Follow [Connect a repository](Connect%20a%20repository.md) to create a notebook or use an existing one, grant read-only GitHub access, and download it. The guide also explains what to do if the repository list is empty or organization approval is needed.

In Mementara, choose the repository, branch, and an optional folder. Wait for **Available offline** before disconnecting.

## A useful offline check

Search for **compass**, open the result, and bookmark it. Close Mementara and turn on airplane mode. Reopen the app and find the same passage.

[Back to the welcome note](../Welcome.md)

## Updating notes

Edit notes using your usual editor and push them to GitHub. Refresh Mementara to download a new snapshot. A failed refresh keeps the previous snapshot usable.

## Exporting other diagrams

Keep source and preview together: `architecture.puml` with `architecture.puml.svg` or `architecture.puml.png`. The preview is explicitly labeled; Mementara does not send diagrams to a cloud renderer.
