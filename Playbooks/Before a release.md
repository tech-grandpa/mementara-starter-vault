# Before a release

A fictional checklist for the field-reference app in [[Engineering/Keep a useful offline copy]]. Use it as a starting point for your own notes, not as Mementara's release certification.

## Check the thing people came for

- [ ] Open a note from the library.
- [ ] Search a remembered word and land on its passage.
- [ ] Follow a link to another note and return.
- [ ] Bookmark a useful passage and find it again.

## Take it offline

Wait for the notebook to finish downloading. Turn on airplane mode, close the app, and open it again. Find a passage that was not already on screen. A cached page alone does not demonstrate that the notebook is searchable offline. ^airplane

- [ ] Search a downloaded note in airplane mode.
- [ ] Open a downloaded image or PDF.
- [ ] Check that a missing attachment is explained.
- [ ] Confirm the last refresh time is available.

## Interrupt an update

Begin with a useful downloaded notebook. Start a refresh and interrupt the connection. Reopen the app and check that the previous notebook is still readable.

The reason for that behavior is in [[Engineering/Keep a useful offline copy#Why a stale note can still be useful]].

## Leave a useful record

Write down the device, operating system, build, and exact steps. Use fictional notes when sharing examples. A note that says “tested offline” is less useful than one another person can repeat.

See [[Reference/Git commands worth keeping#What changed?|what changed]] before writing the release note.
